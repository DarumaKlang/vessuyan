## 📋 Additional Implementation Guide

### For New Pages, Use This Template:

```typescript
import { Metadata } from 'next';
import { createPageMetadata } from '@/lib/seo';

export const metadata: Metadata = createPageMetadata(
    'Page Title',
    'Page description here (120-160 characters)',
    '/path-to-page'
);
```

### Add Breadcrumb Schema to Pages:

```typescript
import { createBreadcrumbSchema } from '@/lib/seo';

// In component
<script
    type="application/ld+json"
    dangerouslySetInnerHTML={{
        __html: JSON.stringify(
            createBreadcrumbSchema([
                { name: 'Home', url: 'https://vessuyan.com' },
                { name: 'Astrology', url: 'https://vessuyan.com/astrology' },
            ])
        ),
    }}
/>
```
